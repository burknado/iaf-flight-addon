## Ice & Fire: To The Skies (Ice & Fire Community Edition Add-On)

An add-on for Ice & Fire: Community Edition, providing:
- Reworked flight for Ampithere, focused on a more gliding feel.
- Configurable stamina system for flying mounts to limit flight.
- Options for configuring armor and toughness values.
- Options for balancing legendary items from the modpack.
- Options to enable/disable the passive abilities of Ice & Fire armor.
- Configurable modifiers for difficulty of sea serpents and their ancient counterparts.
- Optional spawning of sirens on the beach at night, and the ability to despawn them when it reaches morning.

### How it works
- Start with the mod active, and the configuration file will appear.
- Modify the configuration file and restart the game for it to take effect.

Built on the Ice & Fire: Community Edition mod.

### Version
Latest version works with IceAndFireCE 2.1.3 for Neoforge 1.21.1.
